# Самостоятельное задание «Композиция компонентов» — Декомпозиция интерфейса

Практический проект на React 19 + TypeScript 5 по декомпозиции сложного контентного интерфейса (эмуляция главной страницы Яндекса) на изолированные, задокументированные и настраиваемые компоненты.

## 🚀 Архитектурные решения и паттерны

- **Иерархическая инкапсуляция:** Полный отказ от плоской структуры в `App.tsx`. Элементы строк новостей теперь инкапсулированы внутри независимого секторного компонента `NewsSection.tsx`, что разделяет глобальное управление лэйаутом от логики отображения списков.
- **Документирование TSDoc:** Все созданные компоненты снабжены строгими конфигурационными комментариями в формате `/** ... */`. Это обеспечивает автоматическую генерацию контекстных подсказок среды разработки при наведении курсора на теги.
- **Композиция Виджетов (Children Pattern):** Повторяющиеся блоки (такие как погода, телепрограмма или эфир) сведены к единому универсальному компоненту `WidgetContainer.tsx`, который принимает кастомную внутреннюю разметку из внешнего слоя.

## 🛠️ Стек технологий

- React 19 (Архитектура разделения ответственности)
- TypeScript 5 (Интерфейсы данных и строгое документирование TSDoc)
- Vite 8
- Нативный модульный CSS3

## 🔧 Запуск проекта

1. Установка зависимостей:

   ```bash
   npm install
   ```

2. Запуск сервера разработки:

   ```bash
   npm run dev
   ```
